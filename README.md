## Featured Projects

A selection of applications I've built, focusing on backend engineering, distributed systems, and AI-powered software.

### 01. CodeCompass
**AI-Powered GitHub Repository Q&A Assistant**

An intelligent developer tool that allows users to connect GitHub repositories and ask questions about their codebase, receiving answers grounded in actual source code with file and line references.

**Engineering Highlights**
- Built an asynchronous repository ingestion and indexing pipeline.
- Implemented code-aware chunking using Tree-sitter.
- Combined vector search and PostgreSQL full-text search using Reciprocal Rank Fusion (RRF).
- Integrated optional Cross-Encoder reranking to improve retrieval relevance.
- Implemented source-grounded answers with file paths and line citations.
- Added authentication, repository ownership, chat history, and streaming responses.

**Technology:** Python · FastAPI · PostgreSQL · pgvector · Next.js · TypeScript · Tree-sitter · Groq

[Live Application](https://code-compass-nine.vercel.app/dashboard) · [Source Code](https://github.com/Ashusf90)

---

### 02. StagePass
**Multi-Vendor Event Ticketing and Seat Reservation Platform**

A ticketing platform designed to handle concurrent seat reservations and reliable checkout workflows.

**Engineering Highlights**
- Implemented concurrency-safe seat reservations using atomic database updates.
- Added temporary 10-minute seat locks with expiry handling.
- Built idempotent checkout workflows to prevent duplicate processing.
- Implemented HMAC-SHA256 webhook verification and duplicate event detection.
- Generated signed JWT-based QR tickets.
- Developed atomic single-use ticket check-in and role-based access control.

**Technology:** TypeScript · React · Node.js · Express.js · MongoDB · JWT

[Source Code](https://github.com/Ashusf90/StagePass)

### 03. CloudMesh
**Distributed File Storage System**

A distributed file storage application built around an API gateway and a dedicated storage node.

**Engineering Highlights**
- Designed a gateway-to-storage-node architecture.
- Implemented chunk-based file uploads using 1 MiB chunks.
- Built REST-based communication between storage services.
- Integrated MongoDB Atlas for file metadata and ownership information.
- Implemented JWT-based authentication and protected file operations.

**Technology:** TypeScript · Node.js · Express.js · MongoDB Atlas · React

### 04. WorldForge AI
**Agentic AI Fantasy Adventure Application**

An interactive AI-powered fantasy world where users explore environments and interact with a dynamic narrative through natural-language actions.

**Engineering Highlights**

- Implemented RAG to ground generated responses in fantasy-world lore.
- Used ChromaDB and Sentence Transformers for semantic retrieval.
- Added structured LLM outputs and Pydantic schema validation.
- Built an evaluation pipeline achieving 96% first-pass schema validity across 50 evaluated actions.

**Technology:** Python · Streamlit · Gemini API · ChromaDB · Sentence Transformers · Pydantic
